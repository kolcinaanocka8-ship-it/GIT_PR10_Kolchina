# Настройка и конфигурация в GitHab
![Автор проекта](1.jpg)
## Описание программы
Это приложение может:
+ Вывод текущей даты
+ Вывод номера учебной группы
+ Вывод фамилии и имени студента (ФИО)

**Структура папок:**

| Файл / Папка | Назначение |
| :-: | :-|
| `.github/workflows/` | Папка с конфигурацией GitHub (содержит файл `main.yml` для автоматической сборки ). |
| `.gitignore` | Файл, исключающий временные и системные файлы из репозитория Git. |
| `Program.cs` | Главный файл приложения на C#, содержащий логику вывода текущей даты, группы и ФИО. |
| `Project.csproj` | Файл конфигурации проекта .NET. |
| `README.md` | Документация проекта. |

Эти инструкции помогут запустить на вашем локальном компьютере программу для вывода текущей даты
### Необходимые условия
Для запуска и приложения вам потребуется установленный **.NET**, скачать его можно с официального сайта разработчика

Проверить установку можно в терминале командой:
> bash
>
> dotnet --version
### Установка
1.  Клонируйте репозиторий на локальный компьютер
> git clone Ссылка_на_проект
2. Перейдите в папку с проектом
> cd Название_папки
3. Запустите приложение
4. В консоли вы увидите результат
